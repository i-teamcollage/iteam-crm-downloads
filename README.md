# I-Team CRM: installers

This repository holds only the installer files for **I-Team CRM** by I-Team Collage. It contains no code.

**Download:** https://iteamcollage.com/products.html#download. You can also use I-Team CRM in your browser at https://iteamcollage.com/app/

- **Windows 10 and 11** (64-bit): `I-Team-CRM-Windows.zip`. Extract it, then run `Install.cmd`.
- **Mac** with Apple silicon (macOS 12 or later): `I-Team-CRM-Mac.dmg`.

The installed app updates itself, checking each update against I-Team Collage's signing key.
